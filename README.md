Aviso: Este es un proyecto comunitario y no oficial. La documentación original pertenece al proyecto Ren'Py. Si encuentras errores de traducción o interpretación, puedes abrir un Issue o enviar un Pull Request.

## Sobre este proyecto

renpy-docs-esp es una traducción al español de la documentación de Ren'Py cuyo objetivo es facilitar el acceso a la información para la comunidad hispanohablante. Este proyecto busca mantener una traducción clara, consistente y lo más fiel posible a la documentación original.

Si encuentras algún error, una traducción mejorable o contenido desactualizado, eres bienvenido a contribuir mediante un Issue o un Pull Request.
